The flow

Desktop and phone move through the same states together.

01

Pair

Desktop: QR + code card. Phone: camera opens straight away.

02

Connecting

Found → Securing → Starting. Shows the PC name.

03

Live

Desktop: full video, auto-hide bar. Phone: Live dot + big Stop.

04

Reconnecting

Amber pill, auto-retry. Pair again only if it fails.

05

Return

“Tap to connect” to the last device. QR is the fallback.

Implementation plan

Small phases. Each one is shippable and testable on its own (Android first).

Phase 1Tokens

Shared design tokens

  • Create packages/design-tokens with the colors, radius, spacing and type above.
  • Export as CSS variables (desktop) and a TS object (mobile).
Done when both apps import the same tokens.
Phase 2Showcase

Clickable prototype — apps/design

  • Vite + React. Desktop and phone frames side by side.
  • A state switcher: Pair → Connecting → Live → Reconnecting → Return.
  • Fake video, no real connection. Run with pnpm dev:design.
Done when you approve the look and flow.
Phase 3Desktop

Desktop receiver redesign

  • Add a single connectionState that drives which screen shows.
  • Split receiver-workspace.tsx into Pair, Connecting, Live, Reconnecting views.
  • Live: video fills window, floating bar auto-hides after 2s.
  • Map raw statuses to plain-language messages.
Done when pairing UI disappears once live, and returns on disconnect.
Phase 4Mobile

Phone app redesign

  • Replace tabs and stream-test with one stack: Home → Pair → Connecting → Live.
  • Scanner-first Pair screen; “Enter code” as a fallback sheet.
  • Live screen with big Stop and a Details bottom sheet for stats.
  • Keep screen awake + stop-stream notification.
Done when a first-time user pairs without reading instructions.
Phase 5Polish

Reconnect & memory

  • Remember the last paired PC; “Tap to connect” on both sides.
  • Auto-retry for ~15s before asking to pair again.
  • Motion pass: fades between states, scan haptic.
Done when a second session takes one tap.

Rules to keep it premium

  • Blue is rare. Only for the main action and “live”. Never decoration.
  • One task per screen. If it’s not needed now, hide it.
  • Plain words. “Reconnecting…”, not “ICE state: disconnected”.
  • No gradients, no glow. Depth comes from surface steps and 1px borders.
  • Motion is short. 150–250ms fades. Nothing bounces.
